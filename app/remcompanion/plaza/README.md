# 功能广场

默认首页是功能卡片目录，点击“进入”打开对应功能；功能内可返回目录。
目前包含五子棋、像素花园、单词卡片、本地词典与主动陪伴设置。

规则和存档与聊天、大模型、TTS 分开。没有额外服务，所有游戏均可离线使用。

- gomoku.py：新局默认 19×19 无禁手五子棋；旧局保留存档尺寸，含 moves 却缺 size 的旧格式仍按 15×15 恢复；空对象表示没有棋局，采用新局尺寸。GomokuGame 负责合法落子、胜负、悔棋、
  本地对手与基模坐标验证。基模失误/超时由本地对手继续。
  默认为本地启发式算法，不调用模型、不耗 Token；勾选才使用当前聊天模型。
- garden.py / farm_layout.py：39 个稳定编号，34 块可耕格；14/22/27/35/39 保持不可耕，旧九块坐标不变。种子成熟时间是公开规则；必须浇水后才可收获，
  关闭软件期间照常累计时间。
- words.py：自定义 CSV/TSV/TXT/JSON 导入；大小写去重；复习与词库同存档。
  记住后次日复习，没记住 10 分钟后再见。导入失败不会部分覆盖。
- dictionaries.py / _mdx.py：MDX 本地释义与例句；库位于 data/plaza/dictionaries，导入同样集中于此。只读查词，不联网、不调用模型；明确添加才写入词卡，重复词不覆盖复习记录。不支持 v3、LZO、授权密码与 MDD 媒体。
- companion.py：默认关闭的主动陪伴，按最近交互计算间隔，
  使用本地时间、支持跨午夜安静时段。
- storage.py：同目录临时文件原子替换。损坏 JSON 保留，不静默覆盖。

实际页面：ui/plaza_panel.py。构造方法为
PlazaPanel(parent, project_root, on_chat_prompt, on_notify, on_model_request=...)。

on_model_request(prompt, on_reply) 的回包可从工作线程调用；
页面只通过队列在 Tk 主线程处理回包。独立基模请求不写聊天记忆、不产生 TTS。
讲解功能通过 on_chat_prompt 进入普通聊天。
主聊天交互后调用 record_activity()；destroy() 会取消所有 Tk 定时任务。

用户数据：data/plaza/gomoku.json、garden.json、words.json、companion.json。
打开存档前请保留备份，手动修改后点“重新读取当前存档”。只重读当前活动，
不清空聊天、不改变其他活动；损坏文件仍保留，修复后可再次重读。

UI 的存档规则位于 ui/plaza_persistence.py：先在副本操作，保存成功后才替换
当前对象。无法写入时不推进棋局、不增加收获/复习次数、不显示成功；解除
文件占用后可以重试。词卡管理列表过时会拒绝按旧索引删除，需重新打开。
重读五子棋会取消旧回包，并用离线对手继续尚未结束的白棋回合，不额外调用模型。
