# 通用本机任务

`task-config.json` 给出 started/completed/failed 的显式 argv，以及 batch_wrapper_argv。先启动本机接收器，再检查路径和参数并主动运行。

运行时在导出包的 `runtime/` 内，只有标准库代码和当前系统实现；需要 Python3.8+，不需要 app/ 源码树。不要删导出目录；移动/移机后重新导出。脚本不会复制接收器 token 或模型登录资料。

wrapper 要求 --batch，只能包装明确的非交互单次任务，保留宿主 stdout/stderr 和退出码。退出 0 提醒完成，非 0 提醒失败；Ctrl+C 提醒取消并清理其自己启动的进程树。不会删除任务产物。不要拿常驻 GUI/TUI/模型 API 服务退出作为任务结束依据。

常驻软件采用完成 marker 或真实任务事件通知。接收器端口动态读取，token 不写入导出配置。监工取消是停止观察，不擅自停止宿主模型。Windows 使用 Job Object，Linux 使用独立进程组；取消时只对仍可确认身份的自有组发信号。Linux 父进程已被回收等无法确认身份的情况会告警并不追加组信号，可能留下后代，不能保证任意外部程序完整回收；不杀他人的模型/服务。
