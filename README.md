# RemWorkspace

中文 | [English](README.en.md) | [日本語](README.ja.md)

因为re0第四季结束我的雷姆又回来了！所以决定做点东西庆祝一下，所以有了这个codex打工打出来了雷姆主题的agent平台！
<img width="2566" height="1661" alt="image" src="https://github.com/user-attachments/assets/913500ba-4950-44f5-9196-318474e63f44" />

RemWorkspace 是一个本地优先的桌面工作空间，把聊天、雷姆桌宠、日记、每日待办和专注计时放在一起。你可以在主窗口聊天，也可以用跟着她的小气泡随手输入，休息时玩一会儿农场或五子棋。

仓库名是 `remworkspace`，当前软件界面和程序文件仍叫 RemChat，Python 包仍是 `remcompanion`。下面的按钮名、启动命令和文件路径都沿用软件实际名称。

支持 Windows 和 Linux x86_64。到“设置 > 通用”切换简体中文、繁體中文、English 或日本語。界面会跟随切换，自己的聊天、日记、文件名不会被翻译。

0.1.1 修正了 Windows 动作边缘的黑色底晕，补齐新页面和弹窗的四语言文案，也让工作跟踪环在专注幕布上继续显示。隐藏过的跟踪环不会因此重新开启。

日常使用请到 [Releases](https://github.com/liang-bm/remworkspace/releases) 下载对应系统的程序包。程序包带桌宠动作，不需要先安装 Python 或语音模型，就能打开界面、写日记、管理待办、专注计时和玩农场。聊天需要配置自己的模型服务。语音默认关闭，想听朗读时再按引导安装。

GitHub 源码不含个人存档、API Key、声线权重或模型运行环境。从源码启动需要准备角色素材和 Python，步骤在本文的[从源码运行](#从源码运行)一节；Release 中的动作素材包可以解压到项目根目录。

## 第一次打开

如果你已经有完整程序包，Windows 打开 `desktop-app/RemChat.exe`；Linux 安装后从应用菜单打开 RemChat，也可以运行包里的 `desktop-app/RemChat`。

1. 只看到桌面雷姆时，右键她，选择“显示 / 隐藏主聊天窗口”。
2. 打开左侧“设置”，在“通用”的“界面语言”里选你习惯的语言。
3. 到“模型与 API”选择聊天模型。用自己的在线 API 时，填写 Base URL、API Key 和模型 ID，点“保存并启用”，再确认聊天输入栏下方选中了这个模型。
4. 已有本机兼容服务，可以填它的本机地址。想安装本地聊天模型，选择“本地 Qwen”后点“安装本地模型”，按页面状态完成安装和启动；本地模型需要另占磁盘和内存。
5. 回到聊天页，输入一句话，按 Enter 发送。Shift + Enter 换行。顶部“播放”初始关闭，不影响文字聊天；第一次打开它会进入语音准备引导。

保存 API 配置不会自动测试。点“测试连接”或“获取模型”才会发请求，所选服务可能收费。编程套餐接口有自己的用途限制，不能当作通用聊天 API 使用。

## 聊天、模型和记忆

主窗口适合看完整回复，跟随雷姆的小气泡适合随手说一句。它们共享当前聊天，不会各建一份会话。顶部“悬浮窗”控制小气泡是否显示。

聊天消息支持 Markdown，包括标题、列表、引用、表格和代码块。代码可以单独复制；标成 Markdown 的示例有源码和预览切换。长回复可以展开，上翻看旧消息时不会强行跳回底部。消息右键菜单可以复制原始 Markdown。代码和 HTML 都不会执行。

输入栏的“＋”添加本轮附件，“选择工作空间”指定相关目录。选择目录本身不会扫描或修改全部文件。发送前确认本轮附件；移除附件只取消发送，不删除原文件。Ask / Plan 等模式使用页面列出的能力，软件不会因此取得任意命令执行权限。

一个提供商可以保存多个模型。模型 ID 要填服务实际接受的名称；不清楚上下文或输出上限时可以留空。顶部的中文 / 日本語是朗读选择，界面语言不会翻译已有聊天，也不会自动改声线。聊天默认以中文回复。

想让雷姆记住一个偏好，可以说“请记住，我喜欢安静一点的提醒”，然后到“记忆管理”核对保存结果。这里也可以修改、删除、导入或导出记忆。希望始终遵守的偏好可以直接写进“对话与人格”的长期指令。聊天、长期记忆和日记分别保存，改其中一项不会改另一项。

## 桌面雷姆和外观

右键雷姆可以显示主窗口、调整空闲状态或退出软件。她会自然待机，也可以打盹和自己慢慢走动。睡着时靠近不会触发跳跃，轻点她会播放唤醒动作；拖动则按拖拽处理。主聊天打开、正在回复或专注时，空闲动作会让位。

“设置 > 外观与动作”里调整主题、壁纸、壁纸淡化和桌宠大小。背景管理可以导入自己的图片、挑选背景，或按启动和日期换图。Ctrl + / Ctrl - 调整主聊天字号，不改变小气泡字号。

“动作工作台”用于导入、预览和管理自己的逐帧动作。RemChat 的桌宠使用图像帧动画；导入素材时需要按页面要求准备帧和动作信息。

## 麦克风输入和朗读

先到“设置 > 语音输入”启用识别方式。语音转文字（ASR）和把回复读出来是两套设置。

- 主聊天、跟随雷姆的小气泡：点击麦克风，录音时显示音量波形。可以暂停、继续、停止转写或取消。识别出的文字填回草稿，你确认后再发送。
- 日记编辑页：点“语音记录”，在计时弹窗中录音。停止转写后，文字插入当前日记。

切换聊天或日记会取消这一轮录音，旧结果不会填到别的记录里。录音或识别失败不会清掉原草稿。临时录音处理后删除，不会自动变成日记附件。

在线识别需要填写接口和模型，例如硅基流动的 `https://api.siliconflow.cn/v1/audio/transcriptions`、`TeleAI/TeleSpeechASR`。可以保存独立 ASR 密钥，也可以使用自己保存的提供商密钥。停止录音后，音频会发送到所选服务；在线识别可能计费。实际支持的识别语言取决于该模型。

本地模式可以选 Whisper.cpp 的 `whisper-cli` 和匹配模型，或连接自己启动的本机兼容转写服务。软件不自动下载 ASR 模型。本机服务地址使用回环地址，例如 `http://127.0.0.1:8080/v1/audio/transcriptions`。

Windows 需要允许应用访问默认麦克风。Linux 使用系统的 `pw-record`、`parec` 或 `arecord`，至少要有其中一种，并在桌面会话中启动。

### 想听雷姆朗读

点击主聊天顶部的“播放”，或小气泡的 ♪ 按钮，会打开语音准备引导。主窗口和气泡共用同一个开关；暂不开启也可以继续聊天。

1. 先准备 FFmpeg 和 C/C++ 编译工具。Windows 从 [FFmpeg 官网](https://ffmpeg.org/download.html) 选择 Windows 版，把解压后的 `bin` 放在软件安装目录的 `engines/ffmpeg/bin`，保留 DLL 和许可证；另安装 [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) 的 C++ 工作负载。Ubuntu / Debian 可在终端运行 `sudo apt install ffmpeg build-essential`。语音依赖中的两个组件需要编译；软件不会替你运行 sudo 或安装系统工具。
2. 在引导里选 CPU 或 NVIDIA GPU，点“安装环境”。不确定就选 CPU；GPU 需要支持 CUDA 12.8 的驱动。安装器下载固定版本的 GPT-SoVITS、Python 环境和基础模型，校验后检查依赖。首次下载量较大，请预留几 GB 空间和等待时间。关闭进度窗口不会取消正在进行的安装，语音仍保持关闭。
3. 点“打开 Google Drive 资料”，或直接进入[声线下载文件夹](https://drive.google.com/drive/folders/1RvbxWWKFjzlHd4PHGXQU9_3EExOs4DgM)。下载 `rem-voice-inference-v2pro.voice-parts.json` 和三个 `rem-voice-inference-v2pro.zip.001`、`.002`、`.003` 文件，放在同一个文件夹，保留原文件名。不要手动解压。
4. 点“导入推理包”，选择 `.voice-parts.json` 清单。软件会自动校验、合并，导入权重、参考音频及对应文字，再用本机账户密钥加密保存。检查就绪后，点“开启语音”。以后用“播放”或 ♪ 切换即可。

推理包约 256 MiB，已用它完成 CPU 的中文和日文合成验证。它不包含原始训练数据；使用朗读不需要下载训练集，也不用重新训练。全新机器的完整安装仍受系统工具、网络和驱动影响，失败时引导会保留错误信息，文字聊天不受影响。

安装器使用的逻辑路径是 `models/tts/rem/gpt/rem-gpt.ckpt`、`models/tts/rem/sovits/rem-sovits.pth`、`voice-source/reference.wav` 和 `voice-source/reference.txt`；导入后文件进入资源保险库，原下载包不会自动删除。基础引擎在 `engines/GPT-SoVITS`，独立语音环境在 `runtime/gpt-sovits`。不要复制别人的账户密文来代替导入。

中文 / 日本語选择朗读语言。在线聊天 API 和本地声线是两件事，配置聊天 API 不会同时获得声线。只想文字聊天，可以一直关闭语音。

## 专注和倒计日

主聊天顶部的倒计日可以直接点进去编辑。输入事项和 `YYYY-MM-DD` 格式的日期，可以一次保存多个事项。用“展示”选择顶部显示哪一项；没有指定时，优先显示最近到期的事项。当天显示“就是今天”，过去的日期显示已经过了多少天。

在顶部“专注”设置分钟数后点“开始”。当前聊天壁纸会铺成桌面前层幕布，上面有蒙版和倒计时动画，雷姆仍然可见。专注期间小气泡暂时隐藏，结束后恢复原设置。

幕布上可以“暂停 / 继续”，点“结束专注”或按 Esc 随时退出。计时结束后回到桌面并提醒休息。多显示器共用同一计时。它不修改系统壁纸，也不锁住电脑或禁用系统快捷键。

Linux 的置顶和多屏效果依赖 X11 / XWayland 与窗口管理器，原生 Wayland 可能限制这些操作。

## 日记和每天的待办

打开“功能广场 > 日记”，先看到按日期、时刻排列的时间线。用月历定位日期，点“今天”回到当天；“写一刻”新建一篇，“阅读 / 编辑”打开已有记录。编辑完用“返回总览页面”回到时间线。

正文可以直接用工具栏加粗、高亮、插入标题、列表、引用、彩色表情和附件。选中文字后有小浮栏，右键或 Shift + F10 打开完整格式菜单。也可以直接输入 Markdown，格式会在同一个编辑框里实时显示，不用切换编辑与预览。

插入代码时点“代码块”，选语言并填写代码。代码有语法配色；“复制”复制完整代码，不带围栏。代码只用于记录，不执行。

日期旁设置标签。总览上方的“搜索日记”跨日期查标题、正文、日期和标签，支持多关键词及部分模糊匹配；点击结果打开实际记录并定位内容。清空搜索回到时间线。日记搜索在本机进行。

每日待办放在当天记录前面。同一天写多篇日记，仍共用这一份清单。总览右上角的“设置日记模板”可以选星期、填写正文模板和每行一项的固定待办。对应日期打开时生成一次清单，新日记使用当天启用的模板，旧正文不会被覆盖。

图片、音频、视频和普通文件都能作为附件加入。照片有缩略图，音视频点开后交给系统播放器；普通文件只打开所在目录，不自动执行。每篇最多 64 个附件，单个文件最多 128 MiB。附件保存在本机，不自动交给模型。

日记会在书写停顿后自动保存，也可以点“保存”。保存失败时草稿会保留，先处理页面提示再离开。删除进入回收站，可以恢复。用“导入 / 导出”导入旧文本或 Markdown，或用 `.remjournal` 保留记录格式、时间、标签和附件。

## 农场、单词卡和五子棋

### 像素花园

在“功能广场 > 像素花园”进入农场。点击草地走过去，方向键或 WASD 移动，数字键 1 到 4 选择耕地、播种、浇水、收获，空格或 E 使用工具。种下作物后记得浇水，成熟后收获。

目前有萝卜、胡萝卜、蓝铃花、番茄、玉米、南瓜、草莓和向日葵。作物按现实时间成长，关闭软件不会重置进度。水壶可以在左下水井或右上池塘码头装满；入口小门按 E 开关。树、石头、围栏和水面会挡路，木桥可以走。

默认视角跟随雷姆，“全图视角”查看整个农场。场景预览可以切季节和昼夜。小屋目前未开放，现有玩法在屋外农场。

### 单词卡片

在“功能广场 > 单词卡片”导入本地词典或自己的词卡。选词典看释义和例句，用“记住了 / 还没记住”记录复习，自己的理解写在“我的笔记”。词卡和笔记可导入、导出。

“AI帮记”才会调用当前模型。生成的解释和例句先展示给你；点“解释加入笔记”或“添加所选例句”后才保存。词典原文和你保存的材料分别显示。

### 五子棋

在“功能广场 > 五子棋”开始对弈。新棋盘为 22×22，黑棋先手，连成五子获胜，可以悔棋、看提示或重新开始。

默认对手是本地算法。勾选“让当前聊天模型参与落子（耗 Token）”才会调用模型；棋局讲解也需要主动点击。关闭该选项后，普通对局不需要 API。

## 提醒、项目过程和追踪环

“功能广场 > 主动陪伴”设置提醒间隔和安静时段。自动提醒默认关闭，也可以先“体验一次提醒”。这里的空闲指 RemChat 内没有操作，不会监听整个电脑的键盘和鼠标。回复、播放语音或专注期间会暂缓自动提醒。

“功能广场 > 项目过程”用来回看本机工具留下的会话记录。选择工具、日期和主会话，再看公开用户输入、阶段信息与 Token 活动。能读取的来源以列表标记为准；“暂不支持”的来源不会被当作已经接入。“跟随最新”更新到新记录，选择历史会话会暂停跟随。

在“接入与会话管理”里把需要观察的会话加入桌面追踪。追踪环显示同步状态；侧栏“恢复跟踪环”或“设置 > 通用”可以找回隐藏的环。停止观察不会停止宿主工具的任务。只有宿主明确提供的原生目标或公开 `/goal` 才会显示为目标，普通聊天不会自动变成任务目标。

项目指令和提示词存档来自可读取的本机记录。查看项目指令时显示真实工作目录里的文件，编辑实际文件会影响对应项目；不会显示宿主的内部思考或隐藏系统提示词。

## 应用、MCP、技能和用量

这些入口在“设置 > 接入资源”，默认都需要你明确选择是否启用。

“应用”卡片通过已注册的 `codex://` 链接打开 Codex 的连接或应用页面，登录和授权在那里完成。需要先安装支持这些链接的 Codex；RemChat 不保存或复制它的登录令牌。打开页面不代表已经连接，打开应用草稿也不会自动发送。

“MCP 服务”配置外部工具连接。常用预设有 Context7、Playwright、Sequential Thinking、Filesystem、Memory、Fetch、Git 和只读 GitHub。选预设先得到一份未启用的草稿；确认路径、参数与权限后保存，再明确连接。它不会因选中预设就安装软件或启动服务。

“技能库”管理本地技能文件，“事件 Hook”和“接入草稿”管理明确配置的接入动作。导入配置不会自动开启连接或命令。只连接自己了解、信任的服务。

“全部用量”看本机采集到的 Token 日历与趋势，可以按模型、日期范围和指标筛选。未采集的日期是未知，不等于零；已记录值与观察增量分别显示，不重复相加。费用只有来源给出时才显示。

## 数据、备份和隐私

聊天与长期记忆在 `data/memory.sqlite3`，日记和其他活动在 `data/plaza/`。备份日记时，同时保留 `data/plaza/diary.sqlite3` 和 `data/plaza/diary-media/`；只复制数据库会缺附件。倒计日在 `data/countdown-days.json`。

聊天和日记目前没有数据库级加密。共用电脑时请保管自己的系统账户和备份。选择远程聊天 API 后，消息和用于该请求的历史、记忆上下文会发送给所选服务；在线 ASR 会发送录音，联网搜索会发送查询。日记及附件不会自动上传。

API Key 使用 Windows 当前账户的 DPAPI 或 Linux 系统 Secret Service 保存，配置导出不带密钥。更换 API 端点主机后需要重新确认凭据。

资源保险库使用 AES-256-GCM 保存私有声线，密钥由系统账户保护。受保护资源默认允许本机朗读，关闭训练和原始导出；使用时临时解密，正常结束后回收。它不授予素材版权，也不能阻止当前账户或管理员在使用阶段读取。强制杀进程或断电可能留下账户专用的临时目录。

保险库和密钥恢复材料要单独留在本地。Windows 换账户、Linux 丢失系统密钥库后，密文不能直接恢复；Linux 的密钥条目还按安装路径隔离。不要把 `data/`、真实配置、模型、声线、资源保险库或恢复包提交到公开仓库。

记忆默认使用 SQLite + FTS5 搜索。可选的 sqlite-vec 向量检索需要真实的本地 Embedding 服务，默认不启用，也不自动下载模型。日常使用不需要先部署向量服务。

## 从源码运行

源码需要 Python 3.12 和 Tk。先放好自己有使用权的角色素材：待机帧位于 `app/remcompanion/assets/pet/idle/idle_*.png`，其他动作在 `app/remcompanion/assets/pet/actions/`。已有本地保险库的用户可以按下一节恢复素材。公开源码不附这些文件。

### Windows

在项目根目录打开 PowerShell，建立专用环境：

```powershell
py -3.12 -m venv runtime\control
.\runtime\control\Scripts\python.exe -m pip install Pillow==12.3.0 Pygments==2.19.2 cryptography==50.0.2 sqlite-vec==0.1.6
if (-not (Test-Path config\rem_companion.toml)) {
    Copy-Item config\defaults\rem_companion.toml config\rem_companion.toml
}
$env:REM_HOME = (Get-Location).Path
$env:PYTHONPATH = Join-Path (Get-Location) 'app'
.\runtime\control\Scripts\python.exe -m remcompanion.desktop
```

已有配置会保留。下次启动仍使用这个环境里的 Python；也可以先激活 `runtime\control` 环境，再运行 `platforms/windows/从源代码启动.cmd`。

### Linux

在图形桌面会话中打开终端，从项目根目录执行：

```bash
test -f config/rem_companion.toml || cp config/defaults/rem_companion.toml config/rem_companion.toml
bash platforms/linux/scripts/Setup-LinuxDesktop.sh
bash platforms/linux/Start-RemChat.sh
```

安装脚本准备独立的 Linux 前端环境、Tk 和字体，会下载所需依赖，不安装系统软件、聊天模型或声线。系统需有 X11 / XWayland、Xft 和 fontconfig；麦克风工具、系统密钥库及本地模型运行环境另行准备。Windows 的运行环境和账户密文不能拿到 Linux 直接使用。

有可安装的 Linux 程序包时，解压后使用包内 `Install.sh`；标为私有本地包的归档按其提示加 `--private-local`，不要将它当作公开发行包上传。

## 本地资源恢复和可选向量检索

先配置好上面的 Python 环境与 `PYTHONPATH=app`。下面的 `python` 指这个环境中的解释器，Windows 可以替换为 `.\runtime\control\Scripts\python.exe`，Linux 为 `runtime/desktop-linux-xft/bin/python`。

```text
python -m remcompanion.private_resource_cli status
python -m remcompanion.private_resource_cli verify
python -m remcompanion.private_resource_cli restore-local --vault-directory "YOUR_PRIVATE_VAULT"
```

把 `YOUR_PRIVATE_VAULT` 换成仓库外保险库的实际绝对路径。恢复需要原账户及对应密钥。`restore-local` 恢复角色素材，声线继续留在保险库里按需使用。只有再加 `--include-configuration` 才恢复原个人指令和 API 配置，这一步仅用于自己的本地安装。

要启用向量检索，先自行运行真实的本地 Embedding 服务，再填写它的模型名和版本标识：

```text
python -m remcompanion.private_resource_cli semantic --allow --base-url http://127.0.0.1:8081/v1 --model YOUR_EMBEDDING_MODEL --revision YOUR_MODEL_REVISION
```

这个命令只保存设置，不下载或启动模型。换模型权重时也要改版本标识；服务不可用时回到普通记忆搜索。

## 遇到问题

- 只有雷姆、找不到聊天页：右键她，显示主聊天窗口。
- 模型连接失败：检查当前选中的模型、Base URL、模型 ID 和密钥；本地模式确认服务已启动。朗读失败时可以先关“播放”，文字聊天仍能使用。
- 麦克风没有声音：检查默认输入设备和系统权限；Linux 还要检查录音工具是否可用。
- 日记保存失败：保留当前草稿，按页面提示检查路径、磁盘空间或权限，再重试。
- Linux 字体缺字或复制失败：检查 CJK 字体；WSLg 下按提示准备 `wl-clipboard`。
- 受保护 TTS 提示端口未知：确认那是自己启动的服务，不要借用不明本机端口。

反馈问题时说明系统、操作步骤和具体错误即可。请不要附上 API Key、私人聊天、日记、声线文件或恢复包。

普通问题和功能建议可以通过仓库的 [Issues](https://github.com/liang-bm/remworkspace/issues) 提交，中文、English、日本語都可以。涉及漏洞、凭据或私人数据的问题，请按[安全说明](SECURITY.md)私下报告；修改代码和说明前可以先看[贡献指南](CONTRIBUTING.md)。
